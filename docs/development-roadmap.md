# برنامه ادامه توسعه

این سند فهرست پیگیری مراحل تایید شده است. هر مورد فقط پس از انجام و بررسی تیک میخورد. پیشنهادهایی که هنوز روش اجرای آنها تایید نشده است، با توضیح مشخص میشوند.

## ۱. تکمیل فنی SEO

- [x] دریافت تمام صفحات محصولات در sitemap برای هر زبان، کدگذاری اسلاگ و حذف لینک تکراری
- [x] بررسی اصلاح sitemap با صفر، ۱۰۰ و ۲۰۵ محصول در دو زبان و اجرای typecheck، lint و build وب
- [x] بررسی پوشش صفحات، زبان ها و لینک ها در SEO در محدوده تایید شده
  - [x] بررسی کد metadata صفحات، robots، sitemap و داده ساختاریافته مقاله
  - [x] تکمیل موارد ناقص پس از تایید محدوده اصلاح و بررسی خروجی واقعی صفحات

صفحه اصلی، فهرست محصولات و وبلاگ metadata مشترک، canonical و لینک زبان دارند. جزئیات محصول canonical و اطلاعات اشتراک گذاری با تصویر اصلی دارد، بدون افزودن قیمت به metadata. درباره ما فقط ترجمه های منتشر شده را لینک میکند. canonical فهرست ها شماره صفحه و فیلترهای پشتیبانی شده را حفظ میکند. خروجی HTML در زبان های فعال و بررسی های typecheck، lint و build موفق بودند. دامنه واقعی باید پیش از انتشار تنظیم شود. لینک ترجمه جزئیات محصول در این مرحله اضافه نشده است، چون API فعلی فقط ترجمه زبان درخواست شده را برمیگرداند؛ اسلاگ ترجمه دیگر حدس زده نمیشود.

- [x] بررسی حذف فایل ها و گالری ها: حذف تصویر مقاله، حذف محصول دارای سه تصویر و تایید نبود رکورد رسانه و پوشه فایل روی دیسک
- [x] بررسی ترجمه ها، قیمت ها و محتوای منتشر شده: پاسخ HTTP در تمام زبان های فعال، قیمت مخفی در فهرست و جزئیات، محدوده قیمت پایه، حالت بدون قیمت، پیش نویس محصول و بایگانی مقاله
- [x] رفع ایرادهای شناسایی شده و بررسی مجدد: مالکیت رسانه، گزارش پاکسازی، Escape و شمارنده برش

موارد پیدا شده و اصلاح شده:

1. گالری مقاله تصاویر متعلق به درباره ما را رد میکند. ایجاد و ویرایش رسانه محصول، مالکیت مقاله، درباره ما، دسته بندی و محصول دیگر و آماده بودن فایل را بررسی میکند؛ تصاویر همان محصول مجاز هستند.
2. حذف دائم محصول وضعیت پاکسازی را به controller برمیگرداند؛ در صورت خطا یا پاکسازی ناقص، پنل به جای موفقیت بدون شرط، هشدار نمایش میدهد.

مرحله دوم در محدوده سناریوهای ثبت شده کامل شد. ۹۹ تست در ۱۵ مجموعه، build و lint بک اند، پنل و وب موفق بودند؛ پس از آخرین اصلاح پنل، typecheck و lint نیز دوباره موفق بودند. تست های سرویس، HTTP و تعامل مرورگر مکمل یکدیگر هستند؛ این نتیجه ادعای پوشش تمام ترکیب های ممکن یا تایید محیط production نیست. build پنل هشدار حجم بالای بعضی chunk ها دارد که در مرحله بهینه سازی بررسی میشود. امنیت پیشرفته، تست فشار و QA محیط واقعی در مراحل بعدی بررسی میشوند.

بک اند محلی برای بررسی فعال شد. درخواست نامعتبر تماس رد شد و چهار منبع مدیریتی بدون ورود خطای ۴۰۱ دادند. پاسخ HTTP محصول منتشر شده با قیمت مخفی در فهرست و جزئیات هیچ مبلغ ذخیره شده ای ارسال نکرد؛ قیمت نمایان و بدون قیمت نیز بررسی شد. ترجمه های منتشر شده محصول و مقاله در تمام زبان های فعال دریافت شدند؛ پیش نویس محصول و مقاله بایگانی شده ۴۰۴ دادند. محصول موقت بدون رابطه دسته بندی در دیتابیس، محصولات مرتبط خالی برگرداند؛ فرم ایجاد همچنان دسته اصلی را الزامی میداند. رسانه مقاله برای محصول دیگر رد شد. داده های قبلی تغییر نکردند. تمام رکوردها، فایل ها و اسکریپت های موقت این تست ها پاک شدند.
