# Life Steel Web

سایت موقت چند زبانه با Next.js. صفحه خانه، فهرست قابل جستجو و فیلتر محصولات و صفحه جزئیات محصول از API داده می گیرند. طرح نهایی سایت و صفحات تکمیلی در فازهای بعدی ساخته می شوند.

وبلاگ در مسیر `/{locale}/blog` و صفحه مقاله در `/{locale}/blog/{slug}` قرار دارد. فقط مقاله ها و ترجمه های منتشر شده نمایش داده می شوند. فهرست دارای جستجو، فیلتر دسته بندی و برچسب و صفحه بندی است. متن بلوکی، گالری اختصاصی، ترجمه های منتشر شده و مقاله های مرتبط با دسته بندی اصلی از API دریافت می شوند. نمایش فعلی موقت است و فرم مدیریت مقاله بدون تغییر باقی مانده است.

سئو مقاله شامل عنوان و توضیحات هر زبان، canonical، hreflang، Open Graph، Twitter Card و داده ساختاریافته Article است. تصویر اشتراک گذاری از تصویر اصلی مقاله گرفته میشود؛ بدون تصویر اصلی، کارت متنی ساخته میشود. اطلاعات نویسنده یا تاریخ ویرایش حدس زده نمیشود. پیش از انتشار، `NEXT_PUBLIC_SITE_URL` را روی دامنه واقعی تنظیم کنید. مقاله های منتشر شده در sitemap قرار میگیرند.

```powershell
npm install
npm run dev
```

آدرس پیش فرض `http://localhost:3001/fa` است. `API_PROXY_TARGET` در صورت نیاز نشانی backend را عوض می کند؛ مقدار پیش فرض `http://127.0.0.1:3000` است. برای بررسی `npm run lint` و `npm run build` را اجرا کنید.
