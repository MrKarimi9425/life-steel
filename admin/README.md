# Life Steel Admin

پنل فارسی و راست به چپ React/Vite با چیدمان و کامپوننت های مشترک پروژه استودیو. امکانات فعلی شامل مدیریت مدیران، زبان و عبارت های سایت، رسانه، دسته بندی، ویژگی و محصول است.

```powershell
npm install
npm run dev
```

Vite درخواست های `/api` را به backend روی پورت 3000 می فرستد. ورود فقط با شماره تلفن و رمز عبور است. مدیر اصلی می تواند مدیر جدید بسازد یا رمز موقت تازه صادر کند؛ رمز موقت تنها در همان پاسخ نمایش داده می شود و کاربر در نخستین ورود باید آن را تغییر دهد.

برای بررسی: `npm run typecheck`، `npm run lint` و `npm run build`.
